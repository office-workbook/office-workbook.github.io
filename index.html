Audio extractor & converter

The YouTube-to-Opus idea, without the middleman: sites like that have to fetch and process the file on their server, which is exactly where a copy can be kept. Pasting a YouTube link can't be done from a page like this one — it would need a server doing the fetching, and that server would see everything. But if the video or audio file is already on this device, its audio can be pulled out right here: MP4, WebM, MP3, M4A, OGG and similar in, WAV or Opus/WebM out. Opus conversion plays the audio through in real time, so a long file takes as long as it lasts.

The file converter

It swaps images between PNG, JPG, WebP and AVIF, pulls the audio out of a video, converts text and data, and fingerprints files with their SHA-256 hash. A file format is really just a — the same picture can travel as a PNG, a JPG or a WebP, and converting it repacks the picture without it ever leaving your device.
